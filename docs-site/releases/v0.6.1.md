# v0.6.1

A defect-fix release. LAS 1.4 conversion keeps the vertical datum and the
vertical unit instead of dropping both with the GeoKeys; contour GeoJSON
states the elevation's real unit rather than labelling everything metre; EPT
laszip tiles refuse non-finite positions like the other two decoders already
did; and a truncated `.e57` no longer hangs the parse worker for the rest of
the session. Each fix carries a regression test that fails on the v0.6.0 code.
