# v0.6.8

v0.6.8 is an engineering and provenance release. No product changed evidence
level: the register holds 34 claims, 17 of them at E4 and none at E5.

Most of the work went into what the viewer says about its own numbers. A strided
load carries three nested populations, the count the file declares, the subset
the stride decoded, and the smaller set an analysis gathers, and rows across the
reports named a figure without saying which of the three it described. Those rows
now state their basis, classification reports its measured unclassified share
instead of a hardcoded zero, and two header fields are labelled as what they
actually hold rather than as capture facts.

A heavy local file indexed into the Origin Private File System is now found again
on reopen instead of rebuilt, keyed by a whole-file digest so an edited file is a
miss rather than a wrong hit. Streaming reports readiness for the current view
rather than the whole source, and refines toward the centre of what you are
looking at.

Analysis outputs now refuse rather than substitute where the input does not
support a figure. The hold-out validation reports no statistic on an invalid
parameter or a failed train-only reclassification, and says why. Residual
figures are captioned in the unit they are in, so a scan with no stated vertical
scale reads "source Z units" rather than metres. A two-epoch comparison reports
no volume and no elevation difference on a frame it cannot confirm, and none at
all when no cell is measured in both epochs. The validation record names which
ground classification the surface was fitted from.

The release also adds a Scan QA report, a derived-layers section in the Layers
panel, and support for 3D Tiles REPLACE refinement. An artifact passport and an
evidence boundary inspector are implemented and tested but not yet reachable
from the interface.
