# v0.7.0

v0.7.0 is in development. It has no tag and no publication date, and the figures
below are written at release.

ASPRS class semantics now come from one module instead of a table in each of
eight places, and names depend on the point data record format the file
declares. Class 12 is Overlap Points under the legacy formats and reserved from
format 6, where overlap is carried by a flag. Classes 19 to 22 are named rather
than reported as user-defined.

Classification flags survive a load for the first time. Synthetic, Key-Point,
Withheld and Overlap are read from both record layouts, carried on the point
model, and written back by both LAS writers. Nothing consumes them yet, so a
withheld point still takes part in analysis; that policy is open work.
