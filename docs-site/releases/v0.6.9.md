# v0.6.9

v0.6.9 changes one measurement method and speeds up the paths around it. No
product changed evidence level: the register holds 34 claims, 17 of them at E4
and none at E5.

The interactive stockpile volume is now integrated over a grid rather than summed
over a point sample. Each cell is clipped to the lasso polygon and takes the
median surface within the cell, so the figure no longer moves with how many
points happened to be resident. The estimate is live in the lasso toast and
states its own authority: measured when the source is fully resident, preview
while it is not. A streaming source stays at preview until the whole source is
resident, and a renderer that reports itself ready does not make it so. The
claim stays at E3, checked against synthetic known truth, with field accuracy
unestablished. Beyond the toast the session record, the report and the
measurement CSV still carry the older point-sample volume record.

A local LAZ opens progressively; an ordinary LAS still reads whole under the memory guard. The header prefix is read first, a
worker frames the file from it, and chunks are decoded from a pool by range, so
the file is never resident whole. A stand-in cloud is drawn while the decode
continues, sampled by one global stride so only the preview budget crosses the
worker boundary, and the load telemetry names the file, the plan and the unique
bytes it read.

A computed terrain core is kept on the device and restored when the same
analysis is asked for again. The key is the identity of the analysed input, a
digest of the positions and the classification with the core parameters and the
method generation, so an edited input recomputes. The recorded benchmark
restores in tens of milliseconds where a fresh compute takes seconds, with
byte-identical grids.

Work that cannot run on the main thread now refuses there. A worker failure
falls back only for sizes measured as safe, and anything larger reports a typed
error saying nothing was produced rather than freezing the page. The Analyse
panel says when a result was computed on the main thread.

Four numeric paths were rewritten for speed and held to byte identity against
the code they replace: the DTM aggregation, the ICP target index, the voxel
accumulator and the morphology opening.

The shell and the renderer are decomposed into coordinators over narrow ports,
the action registry is split into contributors and built lazily, and Help is
derived from the action registry and the key binding table. Interface work this
cycle covers one scientific state grammar, a laptop dock tier, results first on
phones, live status announcements and empty states that say what fills them.
The Tools tab opens with a launcher card that lists Measure, Inspect point,
Annotate and Clip box with their keys and hints, counts what the session has
placed, and collapses to a strip while a tool panel is active; Probe stays on
the dock only.
Panel rows now lead with the result: a value that carries the figure is set
larger than its label, figures are tabular, and Layer Health, Export,
Provenance and Scan Intelligence say less and say it in order.
