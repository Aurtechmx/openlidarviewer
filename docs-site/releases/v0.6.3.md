# v0.6.3

A correction and platform-parity release. Eleven defects are fixed, most of them
inert on macOS and load-bearing on Windows: a scroll container whose own
scrollbar could not be grabbed, seven surfaces that shifted content sideways
when a scrollbar appeared, a canvas that cancelled the browser's page-zoom
gesture, a one-pixel breakpoint gap that mounted desktop panels with their
collapse handles hidden, and Apple modifier glyphs printed on Windows. Windows
High Contrast is supported. The LAS memory estimate now accounts for colour,
so a colour-bearing point format no longer admits a budget the device cannot
hold, and the preset contract separates the fields the renderer applies from
the ones it does not.

The targeted mutation campaign closes: M04, M07 and M09 are killed, so all
twelve are detected by the full gate. The broad campaign scores 96.81 over 188
mutants against the numeric core, up from 87.23, with 53 of the 182 detected
mutants killed by timeout rather than by an assertion.

Streaming gains a decoded state distinct from resident, so the point budget
throttles against what has been drawn rather than what has been decoded.
Routing commits through the upload queue is implemented and tested but off by
default, and carries no performance claim: the release criteria ask for WebGPU
and forced-WebGL2 measurements first.
