# v0.6.7

v0.6.7 is a licensing and engineering release. The project license moves to
AGPL-3.0-only from this release onward. Releases through v0.6.6 were published
under MIT and remain available under those terms, and the change does not alter
the license of any bundled third-party dependency or of any test or validation
dataset.

Underneath the license change, a memory-safety hardening wave reworks the read
paths so a malformed or oversized input is refused before it can allocate past a
single shared decoded-byte budget, and the out-of-core store lifecycle is
leak-free with a startup janitor sweeping any abandoned store. Two ingest paths
join them: a very large uncompressed LAS and a chunked LAZ stream out of core
through temporary browser storage in the Origin Private File System rather than
being read whole into memory, and 3D Tiles implicit tiling opens and streams
where an earlier release read only an explicit tile hierarchy.

This release adds no new scientific evidence claim, no new E4 promotion and no
new validation study. The twelve registered products at E4 stay exactly as
validated in v0.6.6. A short run of corrections rides underneath: the profile
PDF max-grade now carries the sign the panel already shows, the Inspector
elevation rows read the source vertical unit instead of assuming metres, leaked
panel-rail observers are disposed, a degenerate profile no longer reports full
coverage over zero returns, and closing the profile workbench restores the
Analyse panel and its contour controls.
