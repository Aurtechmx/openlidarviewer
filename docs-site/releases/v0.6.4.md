# v0.6.4

A classification, report-hardening and interface release. Building
classification now requires firmer ground support beneath a candidate roof, so
scan-edge void artifacts no longer classify as buildings while real buildings on
fully measured ground are kept. `docs/validation/building-support-gate-eval.md`
records a synthetic evaluation: on one labelled corpus the gate removes 480 of
528 artifact roof points and keeps every real-building point. Automatic
classification is return-number aware, a standalone Auto-classify button runs
classification on demand, and auto-classify keeps the scan's natural colour
instead of forcing the class palette.

Four report and UI surfaces fail closed on an unknown CRS linear unit rather
than presenting a length in an unstated unit, annotation `worldPosition` is
populated with the report frame labelled, and remote COPC streaming replacement
is transactional so a failed swap does not leave the previous session partly
torn down.

WebGPU falls back to WebGL 2 when no adapter is present, which fixes an open
crash on iOS WebKit. The mobile GUI is restyled to match the desktop console,
the README leads with a hero image, and multi-layer mounting stays disabled and
guarded while the per-layer frame fixes land.
