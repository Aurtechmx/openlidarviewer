# Descriptor cross-implementation fixtures

Analytic fixtures and independent references for the two terrain descriptors,
TPI and VRM. Both surfaces are chosen to control a known confound so the
comparison measures the algorithm, not an artifact. Generated by
`scripts/generate-descriptor-crosscheck.mjs`; the tools are run once and the
outputs committed. The cross-check tests read the committed references and never
invoke the tools.

- `tpi-quadratic.asc` — a low-amplitude quadratic `z = c·(x²+y²)`, re-centred so
  `|z|` stays small. TPI is translation-invariant in elevation, but gdaldem
  accumulates the neighbourhood mean in float32, whose spacing scales with `|z|`;
  keeping `|z|` small keeps that float32 error far below the tolerance. Closed-form
  interior TPI is `−c·mean(Δx²+Δy²)`.
- `tpi-quadratic__tpi.asc` — gdaldem 3.13.1 `TPI` reference on that surface.
- `vrm-tilted.asc` — a smooth tilted quadratic `z = a·x + c·(x²+y²)`, re-centred.
  The tilt keeps the slope non-zero (no aspect singularity) and the curvature is
  well resolved, so Horn's normal and SAGA's estimator both converge to the
  analytic normal.
- `vrm-tilted__vrm.asc` — SAGA 7.8.2 `ta_morphometry` Vector Ruggedness Measure
  (3×3 window) reference on that surface.

The exact commands, tool versions and resolved paths are in
`reference-runs-descriptor.json`; the input and output hashes are in
`descriptor-SHA256SUMS`. See `tests/tpiCrossCheck.test.ts` and
`tests/vrmCrossCheck.test.ts` for the three-way comparisons.
