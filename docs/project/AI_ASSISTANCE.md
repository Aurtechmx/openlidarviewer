# AI assistance

Generative AI tools were used for drafting, code review, test suggestions, and
documentation editing. Their output was treated as untrusted input: changes were
reviewed by the maintainer and evaluated through the repository's applicable
tests, builds, and validation artifacts.

AI-generated text or values are not used as scientific evidence or credited as
authorship. Claims rely on cited sources and committed validation records.
A. Urias retains responsibility for the design, implementation, interpretation,
and release.
